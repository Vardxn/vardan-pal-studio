## 🚀 Quick Start (Local Development)

All demo websites and the Master Showcase Hub are static HTML5/CSS3/Vanilla JS with zero external framework build overhead.

To serve locally:
```bash
cd /Users/vardan/.gemini/antigravity-ide/scratch/south-delhi-digital
python3 -m http.server 8088
```

Then open in your browser:
- **Master Showcase Hub:** [http://localhost:8088/](http://localhost:8088/)

## 🌐 1-Click Production Deployment

Because the entire repository uses pure HTML5, CSS3, and JavaScript:
- **Vercel / Netlify:** Push to a GitHub repository or drag-and-drop the `south-delhi-digital` folder into Netlify Drop.
- **GitHub Pages:** Enable GitHub Pages on the `main` branch with root `/` as source.
